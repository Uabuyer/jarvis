# Як встановити Jarvis на Mac або Windows

Голосовий асистент у браузері: кажеш «Гей, Джарвіс», і він відповідає українською, шукає інформацію та показує результат на екрані. На встановлення потрібно приблизно 15 хвилин.

## Що потрібно

- **Платна підписка Claude**, яка включає Claude Code. Без неї Jarvis не запуститься. Підписку оплачуєш ти напряму в Anthropic.
- **Chrome або Edge** і мікрофон.
- **Mac або Windows**. Міцний комп'ютер не потрібен, бо основна робота відбувається на серверах Anthropic.

## Крок 1. Встанови Node.js

Завантаж версію LTS з [nodejs.org](https://nodejs.org) і встанови її, як звичайну програму. Потрібна версія 20.12 або новіша.

## Крок 2. Відкрий термінал

- **Mac:** натисни Cmd + Пробіл, введи `Terminal` і натисни Enter.
- **Windows:** натисни Win + R, введи `cmd` і натисни Enter. Використовуй саме це вікно, бо PowerShell може блокувати команди `npm`.

## Крок 3. Встанови Claude Code і увійди

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

Увійди у свій акаунт Claude за підказками на екрані, а потім закрий цей сеанс: введи `/exit` і натисни Enter.

## Крок 4. Завантаж Jarvis

Відкрий [сторінку проєкту](https://github.com/Uabuyer/jarvis), натисни **Code → Download ZIP** і розпакуй архів, наприклад на робочий стіл. Перейменуй папку на `jarvis`.

Перейди в неї в терміналі:

```bash
cd Desktop/jarvis
```

Якщо на Windows робочий стіл лежить в OneDrive, команда буде такою: `cd OneDrive\Desktop\jarvis`. Назва папки `Desktop` може відрізнятися, якщо система українською.

## Крок 5. Встанови і запусти

```bash
npm install
```

```bash
npm run setup
```

Ця команда нічого не змінює, а лише показує, чи все готово. Якщо бачиш `note`, прочитай підказку поруч.

```bash
npm start
```

Не закривай це вікно, поки користуєшся Jarvis. Щоб зупинити його, натисни Ctrl + C.

## Крок 6. Познайомся

1. Відкрий [http://localhost:5173](http://localhost:5173) у звичайному вікні Chrome або Edge.
2. Натисни **Запустити** і дозволь доступ до мікрофона та геолокації.
3. Дочекайся привітання і скажи: «Гей, Джарвіс, що нового в AI цього тижня?»

Наступного разу достатньо перейти в папку `jarvis`, виконати `npm start` і відкрити ту саму адресу.

**Швидкий гайд:** подивись [відео на 2 хвилини](https://youtu.be/lIln8aQpQMM), як керувати Jarvis голосом і руками.

## Керування

| Дія | Що робить |
|---|---|
| «Гей, Джарвіс» | Будить його |
| Пробіл | Говорити без кодового слова |
| Просто заговорити | Перебити його |
| Esc | Завершити розмову |
| D | Показати діагностику |
| T | Перевірити звук |

## Що можна попросити

- «Відкрий нотатки», «відкрий браузер», «відкрий калькулятор»
- «Відкрий налаштування звуку»
- «Відкрий github.com»

Jarvis лише відкриває програми, налаштування й сайти, тому це працює і в безпечному режимі. Змінювати налаштування, писати в програмах або натискати кнопки він так не може. На Windows доступні Chrome, Edge, Блокнот, Калькулятор, Провідник, Paint, Диспетчер завдань і Налаштування.

## Керування руками

1. Натисни **G** і дозволь доступ до камери. Сядь так, щоб руки було видно в кадрі, і подбай про світло.
2. **Вказівний палець** рухає курсор.
3. **Щипок** (великий і вказівний пальці разом) хапає панель за верхню смужку або натискає кнопку.
4. **Відкрита долоня** відпускає панель.
5. **Два пальці** вгору чи вниз прокручують вміст.
6. **Дві руки буквою L** змінюють розмір панелі, якщо розводити їх у сторони.
7. Щоб вимкнути камеру, знову натисни **G**.

Жести працюють лише у вікні Jarvis і з панелями, які він відкрив. Спершу попроси голосом щось показати, наприклад: «Гей, Джарвіс, покажи новини про AI».

## За бажанням: кращий голос

Без цього все працює на голосі браузера. Якщо хочеш звучання краще:

1. Отримай API-ключ на [elevenlabs.io](https://elevenlabs.io).
2. У папці `jarvis` створи текстовий файл із назвою `.env.bridge.local`. У Блокноті Windows обери тип файлу «Усі файли», щоб назва не закінчилась на `.txt`.
3. Додай у нього:

```
ELEVENLABS_API_KEY=твій_ключ
JARVIS_STT_LANGUAGE=uk
JARVIS_VOICE_ID=id_голосу_з_ElevenLabs
```

4. Перезапусти `npm start`.

Нікому не надсилай цей файл і не показуй ключ на відео.

## Тривоги у твоєму місті

Під час першого запуску браузер запитає доступ до геолокації. Дозволь його, і Jarvis сам визначить твою область, район і громаду. Назву місця видно на значку внизу екрана: **перевір, що вона правильна**. Якщо ноутбук переїде в інше місце, Jarvis оновить її під час наступного запуску.

Якщо значок просить дозволити геолокацію:

- **Mac:** System Settings → Privacy & Security → Location Services, увімкни для Chrome.
- **Windows:** Settings → Privacy & security → Location, увімкни службу геолокації.
- **Chrome:** натисни значок ліворуч від адреси та дозволь Location для цієї сторінки, а потім перезавантаж її.

Щоб визначити місце, координати з точністю приблизно до 100 метрів один раз надсилаються сервісу OpenStreetMap, а потім зберігаються лише на твоєму комп'ютері. Якщо не хочеш цього або місце визначено неправильно, вкажи його вручну:

```bash
npm run alerts:find Полтава
```

Скопіюй рядок свого варіанта в `.env.bridge.local` і додай назву місця:

```
JARVIS_ALERT_REGIONS=числа_з_результату_команди
JARVIS_ALERT_CITY=Полтава
JARVIS_ALERT_CITY_IN=у Полтаві
```

**Це лише додаткове нагадування, і працює воно тільки коли Jarvis запущений.** Обов'язково залиш офіційний застосунок тривог на телефоні.

## Безпека

За замовчуванням Jarvis працює у безпечному режимі: шукає та читає, але нічого не змінює.

Команда `npm start -- --writes` дозволяє йому виконувати реальні дії: надсилати повідомлення, видаляти файли, керувати телефоном і браузером. Голосова команда може бути розпізнана неправильно, тому вмикай цей режим лише якщо розумієш ризики.

## Якщо щось не працює

| Проблема | Що зробити |
|---|---|
| Він мене не чує | Відкрий звичайне вікно Chrome або Edge, а не вікно попереднього перегляду, і перевір дозвіл на мікрофон. Натисни D |
| Немає звуку | Натисни T для перевірки звуку |
| `claude` не знайдено | Закрий термінал, відкрий новий і повтори крок 3 |
| `npm` не знайдено | Перевстанови Node.js і відкрий новий термінал |
| Інтерфейс працює, але відповідей немає | Переконайся, що вікно з `npm start` відкрите, а підписка Claude активна |
| Порт зайнятий | Закрий інший запущений Jarvis або перезавантаж комп'ютер |

**Обмеження Windows:** Jarvis поки не може керувати твоїм браузером Chrome. Голос, пошук, інтерфейс та інші функції від цього не залежать.
